# GRACE C. albicans WGS
Repository for WGS analysis of Candida albicans mutants

GATK_variantcalling: standard variant calling with GATK implementing BQSR
GATK_nia: SLURM submission script for GATK_variantcalling
mutect2: Germline variant calling with mutect2 from GATK
mutect2_nia: SLURM submission script for mutect2
consensus_vcf: concatenation and filtering of vcf files from GATK using bcftools
